# 2026-11-05：高输出采样窗口与 90% 电压能力对照

本轮处理大电流请求、接近堵转时的采样拒绝和短暂失力。用户要求先将当前理论最高输出电压乘以 0.9，并允许本轮诊断请求最高 3 A。默认源码因此采用 `dma-v10-windowed-svpwm / 20k90_svpwm`；这个配置选择不是高输出稳定性结论。

## 当前电压与采样行为

当前默认活动电流环电压能力为：

`sqrt(Vd² + Vq²) ≤ 0.9 × Vbus / √3`

12 V 有效母线对应约 6.235383 V dq 幅值。该比例用于 PI 电压限幅与调制，随有效实测母线变化；名义 `config.bus_voltage` 和旧 NVS 电压槽不另加限制。PWM 为 20 kHz、0–90%，通过公共模偏置将最低相钳零。最小脉宽策略与最大占空比分开，因此降低上限不会恢复历史配置的 4% 下限。可显式选择 65% 和 100% 对照配置，默认仍为 90%。

v9 的首槽跨 TEZ 误拒绝修复继续保留，历史证据见[低占空比采样修复记录](sampling-fix-20261105.md)。本轮没有删除被测相的低侧窗口检查、6 µs 软件建立预算或 DMA 回调完成边界检查。6 µs 是固件采用的保守预算，不是本轮实测的模拟建立时间；DMA 回调是软件观察到的完成上界，也不是 ADC 实际采样孔径。因此 `phase_window` 只能说明未通过当前校验，不能证明每组 ADC 数据在物理上都错误。检查是否可进一步放宽，需要补充模拟波形和电流可信度证据。

[TI DRV8316C 数据手册](https://www.ti.com/lit/ds/symlink/drv8316c.pdf) 给出的 CSA 建立时间为 1 µs（30 pF 测试条件）；这不等于板上从 PWM 输入到 ADC 可用数据的完整预算，也不能直接证明现有 6 µs 余量都可以删除。现有遥测未记录 ADC 转换完成的硬件时间戳，无法拆分转换本体与 DMA ISR 调度延迟。

20 kHz 周期为 50 µs，某相的 LOW 总时间为 `50 × (1 − duty)` µs；中心对齐窗口半宽为 `H = 25 × (1 − duty)` µs。现有窗口要求 START 不早于 `−H + 6 µs`、回调结束早于 `H − 1 µs`。当前 START 约在 TEZ 前 1.4 µs：

| 单相 duty | LOW 总时间 | 窗口最早 START | 窗口最晚回调 |
|---|---:|---:|---:|
| 90% | 5 µs | +3.5 µs | +1.5 µs |
| 70% | 15 µs | −1.5 µs | +6.5 µs |
| 65% | 17.5 µs | −2.75 µs | +7.75 µs |

90% 这一行的开始、结束约束无法同时满足，说明接近该上限的相无法通过当前保守窗口判定。若它是重建相，另外两相仍可能有效；固定轮换两相时则可能拒绝部分采样组。不能将 90% 上限解释为全部角度都有连续反馈，也不能将本表视作对模拟采样孔径的示波器测量。

失效样本不进入 PI。偶发失效冻结该次更新；连续约 2 ms 没有可信反馈时请求零矢量恢复并复位 PI，桥仍保持使能。大量间歇拒绝未必增加 `sampling_recoveries`，但会降低实际控制频率和反馈质量。因此需要同时观察拒绝率、原因、有效控制频率与恢复计数。

## 100% 对照镜像：已取得的短记录

[原始固定参考系注流记录](../build/stall-window-20261105/baseline-fixed-injection.json)使用 `20k100_svpwm`，ELF SHA256 为：

`ea6fe5c7c453d673cb8e723ec976ce2b48e7953fefd61a3459949906d75978e7`

每档请求驱动 500 ms，再零输出观察 500 ms。下表的拒绝率和有效频率仅使用首次至末次驱动快照区间，避免准备和零输出阶段稀释高输出异常；原因增量是包含准备、驱动与观察的整轮值，两者统计范围不同。

| 请求 d 电流 | 驱动期拒绝率 | 驱动期有效控制 | 整轮 `phase_window` 增量 | 整轮 `transport` / `pair_change` / 恢复 |
|---|---:|---:|---:|---|
| 0.3 A | 2.75% | 4858 Hz | 1 | 0 / 0 / 0 |
| 0.8 A | 29.86% | 3509 Hz | 746 | 0 / 0 / 0 |
| 1.5 A | 46.24% | 2691 Hz | 1174 | 0 / 0 / 0 |
| 3 A | 57.83% | 2109 Hz | 1339 | 0 / 0 / 0 |

高请求下主要拒绝原因是被测相未通过窗口预算，不是此前首槽比较值一致性门控，也不是 DMA 帧/传输完整性问题。3 A 档只有一个有效后半程快照，记录中的 `stimulus_verified:false` 和整项 `passed:false` 保留；不能凭配置值或单个快照声称实际达到 3 A。各档均无锁存故障，记录末尾为 idle、零占空比，RAM 配置和校准与连接时一致；这些状态不表示高输出采样稳定。

## 90% 对照结果：上限生效，采样稳定性仍未满足

90% 镜像已烧录，ELF SHA256 为：

`6500639dc1c2389da481f799b635d41dc2c3e155adc518d23fdb4dae89fd7ba8`

[500 ms 短检查](../build/stall-window-20261105/candidate90-short.json)仍在较高请求下出现大量相窗口拒绝。随后[长时检查](../build/stall-window-20261105/candidate90-long.json)分别在 0.3 / 0.8 / 1.5 A 请求下驱动 5 秒，3 A 请求下驱动 30 秒，结果如下：

| 请求 d 电流 / 驱动期 | 驱动期拒绝率 | 驱动期有效控制 | 后半程有效快照数 | 固定参考系 Id 均值 | 后半程电压饱和快照 |
|---|---:|---:|---:|---:|---:|
| 0.3 A / 5 s | 1.596% | 4920 Hz | 53 | 0.29694 A | 0 / 53 |
| 0.8 A / 5 s | 63.411% | 1829 Hz | 20 | 0.69993 A | 20 / 20 |
| 1.5 A / 5 s | 65.111% | 1744 Hz | 13 | 0.67710 A | 12 / 13 |
| 3 A / 30 s | 66.524% | 1674 Hz | 111 | 0.62486 A | 111 / 111 |

Id 均值只统计后半程且有效的 USB 快照，不代表所有控制周期的连续电流，也不是外部仪器标定值。3 A 请求档的诊断峰值相电流约 0.912 A，最大指令 duty 约 0.8662，全部后半程有效快照均达到软件电压饱和判据；**没有实际达到 3 A 的证据**。固定角度下，电压圆饱和时某相最大 duty 可以低于 profile 的 0.9 边界。

长时四档均无锁存故障，整轮 `transport`、`sampling_recoveries` 为 0；主要拒绝原因为 `phase_window`。间隔出现的有效采样可以阻止连续 2 ms 恢复条件成立，同时有效控制已降至约 1.7 kHz，所以“没有恢复/故障”不能用作稳定性结论。3 A 档整轮相窗口拒绝增加 99,673，驱动快照区间拒绝总数增加 99,633；这是不同统计区间，不应混作同一总数。

两份 90% 记录均保留 `passed:false`、`cleanup_errors:[]`，原 RAM 配置和校准恢复一致。90% 电压上限生效，但仅降低 10% **未解决高占空比采样丢失**；本轮不擅自将用户要求的 90% 改成 65%。

本次直接观察到的是电压饱和、反馈降频及电流未达到请求，驱动期间没有触发约 2 ms 连续失采恢复；不能将该记录描述为已经复现用户所说的短暂掉电或失能。65% 仅保留为待硬件验证的实验对照配置，本轮没有验证它的堵转电流、手感或温升。

桌面回归 20/20、USB 检查 7/7 通过，仅说明相应数学、回归和通信项目满足检查。最终设备保持 `20k90_svpwm / idle / fault:none / duty=[0,0,0]`，母线约 11.539 V，对应能力约 5.995841 V；原配置和校准保持不变。[验证汇总](../build/stall-window-20261105/validation-summary.json)、[最终状态](../build/stall-window-20261105/final-status90.json)

## 固定初始电角度的有界注流

诊断构建通过 `diagnose` 的 `axis:"d"` 选择固定参考系注流，正式驱动开始时记录电角度，后续不追随转子旋转。目标 d 电流在约 200 ms 内平滑升高，q 目标为零，使用正常电流调节和限流；转子可以在运动界限内向静止定子磁场稳定。此处 Id/Iq 是固定参考系投影，不是转子偏移后的实时转子 dq 分量，也不等于扭矩标定。

请求范围为 0.05–3 A，且不得超过当前运行电流配置；驱动 50–30000 ms，观察 100–1000 ms。机械位移超过起点 0.15 rad、速度绝对值超过 5 rad/s 或运动值无效时中止。期限与运动检查独立于 ADC 通过与否：驱动期结束即请求零电压，观察阶段保持零输出，总期限到达后停机。原有过流、母线与编码器检查继续执行。

`tools/stall_window_check.py` 临时设置自由模式、零阻尼及所需运行电流预算，分档运行，保存实际目标、固定参考系 Id/Iq、母线、电压饱和和采样统计。它把“完成稳定性检查”“已验证非零刺激”“触及电压饱和”“观测电流接近请求”分别记录；请求最高 3 A 不能替代这些证据。脚本退出会尝试停机并恢复进入时 RAM 配置，核对原校准，不写 NVS。固件诊断任务也会在结束时恢复开始诊断前的 RAM 配置。

仅在烧录恢复流程中，`diagnostic_restore_calibration` 可将同一物理设备预先读回的有效校准恢复到 RAM；必须显式携带匹配的编码器名称和完整校准，不使能、不写 NVS。普通 `configure` 不承担校准恢复，接口字段详见[协议](protocol.md)。

本轮尚未使用外部相电流仪器或示波器确认绝对电流、模拟建立时间和器件端波形。固定参考系注流的静态窗口证据也不能直接替代全部转子角度、机械堵转、动态手感或温升验证。
