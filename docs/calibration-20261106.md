# 2026-11-06 v19 双向多点校准

本轮将单向一电周期、末端单点零点校准改为完整双向扫描和独立位置复核。固件标识为 `dma-v19-bidirectional-calibration`，继续使用 20 kHz / 65% PWM 和 5 kHz 控制。默认参数校准、固定电流重复性、取消/失败保护、双向运动、USB 和 NVS 重启恢复均已验证。最终 v19-06 的 60 秒采样健康严格验收通过；前序 v19-05 与原 v16 对照的失败记录仍完整保留，不能用末次通过覆盖。

[最终验证汇总](../build/calibration-20261106/validation-summary.json)与[重启后最终状态](../build/calibration-20261106/final-status.json)汇集运行镜像、结果和终态；下文保留各次原始证据，便于区分最终复测与前序实验。

## 流程与参数

`calibrate` 仅从 idle 启动。依次执行每相零偏采集、三相对应关系和极性检查、对齐、正向扫描、反向扫描、拟合检查及独立复核；全部通过后回到 idle、关闭输出。主机应持续轮询状态，命令被接受不等于校准完成。固件序列最多 120 秒，含零偏准备的总上限为 121 秒；主机默认等待 130 秒，仅为接收固件终态留出余量，不延长固件激励期限。

```json
{"id":1,"op":"calibrate","current":0.16,"max_current":0.25,"voltage":3.0}
```

三个参数均可省略，默认初始校准电流 0.16 A、校准电流上限 0.25 A、电压幅值上限 3.0 V。范围为 `0.02 ≤ current ≤ max_current ≤ 0.25` A、`0.05 ≤ voltage ≤ 3.0` V，`max_current` 还不能超过运行配置的 `current_limit`。电压同时受当前有效母线与 PWM 能力限制。独立校准参数不会修改运行手感配置；电流值依赖当前 `sense_gain`，并非外部仪器校准值。

只有机械停稳失败或回差、方向零点偏差、拟合残差不合格，才允许把电流乘以 1.5 并封顶于 `max_current` 后重试，最多 3 次且共用总期限。电流跟踪、相对应关系、反馈及电压饱和错误不会触发升流重试。默认路径可依次使用 0.16、0.24、0.25 A；本次实机在第二档通过。

相对应关系检查先使用最多 0.5 V 的受限电压，轮流检查 A/B/C 激励下的电流符号与比例。只把独立采到的相电流计为证据，重建的第三相不参与该项判断。它检测接线或采样对应关系错误，不会自动改接线、反转感测增益或校准绝对电流增益。

正反向分别使用 29 个停稳采集点，电角度网格为 `j × π/2`，`j=0…28`；每方向跨越 7 圈电角度，对 7 极对电机对应一圈机械角。两个方向在同一组指令位置采样，保留连续机械角，检查回程一致性。每点经过电流爬升、150 ms 停稳和至少 150 ms / 128 个有效样本的平均窗口；拟合结束后以 6 个不在拟合网格上的位置复核。校准电流环使用指令定子角坐标，无需先信任旧的转子电角度零点。

## 固定验收条件

门限是本工程首次验收的工程设置，修改门限须有新的误差预算或测量依据。失败的校准不能自行放宽门限。

| 项目 | 条件与记录 |
|---|---|
| 零偏覆盖 | enable 和 calibrate 均采集 4 个窗口，每窗口每相 128 个有效样本；每相共 512 个 |
| 零偏均值 | 每相 0.7–2.2 V |
| 零偏噪声 | 按感测增益换算，RMS ≤ 0.12 A，名义均值标准误 ≤ 0.006 A |
| 零偏漂移 | 比较全部窗口均值对；扣除 3σ 随机均值不确定度后的漂移 ≤ 0.02 A，同时保留未经扣除的窗口差 |
| 停稳与跟踪 | 机械角变化 ≤ 0.0035 rad；平均 Id 偏差和 Iq 分量均 ≤ `max(0.008 A, 目标电流×15%)` |
| 扫描覆盖 | 双向各 29 点齐全，每方向机械行程为 0.9–1.1 圈；不补造缺点、不静默丢弃异常点 |
| 极对数 | 正向、反向分别拟合，均相对 7 极对误差 ≤ 3% |
| 方向与聚集度 | 两方向拟合出的编码器方向一致，圆周聚集度 ≥ 0.90 |
| 零点方向差 | 正向零点与反向零点之差 ≤ 0.12 rad 电角度 |
| 最大回差 | 同一指令位置的双向差 ≤ 0.30 rad 电角度 |
| 拟合残差 | RMS ≤ 0.12 rad、最大值 ≤ 0.35 rad，均为电角度 |
| 零点平均 | 圆周平均，正确处理 0/2π；拟合残差和回差保留非取模误差，避免整电周期滑移被隐藏 |
| 独立复核 | 6 点均通过停稳和电流跟踪，最大位置误差 ≤ 0.20 rad 电角度 |
| 主机重复性 | 默认连续 3 次，各次零点两两圆周差 ≤ 0.05 rad 电角度；该要求独立于单次固件验收 |

噪声的名义标准误假定样本独立；分窗口漂移检查提供额外约束，但不能证明不存在所有相关误差。低侧两相电流存在采样时间差，采样有效性门控不能代替外部波形测量。超过 2 ms 的反馈间隔会先归零并重新爬升，超过 10 ms 则失败；同一帧的新鲜重复通知只跳过，既不重复采样，也不清空已取得的有效窗口。

## 结果保留与故障行为

采集、拟合和复核期间保留上一次已接受的 `calibration` 与 `calibration_quality`。只有全部通过才一起发布新的方向、极对数、零点和质量数据。取消或失败时关闭输出，旧结果保留；故障继续锁存，`disable` 不清故障，也不会自动重新使能。

`calibration_report` 表示最近一次尝试，含 `method:"bidirectional_v1"`、阶段、通过/取消状态、失败原因、尝试次数、实际电流/电压上限、29+29 点数、6 点复核数量、拟合和复核指标、相检查及零偏质量。进行新尝试时它会变化；`calibration_quality` 始终对应已接受的结果，成功后为 `verified:true`、方法为 `bidirectional_v1`。

新结果首先用于 RAM。停机 `save` 保留旧 `smartknob/settings_v1` 布局，另写 `cal_quality` 质量记录；质量记录带 CRC，并绑定完整基础校准、编码器身份和感测增益。加载时只有记录完整、数值合格、绑定匹配才报告 verified。缺失、损坏或不匹配的质量记录不会把仍可恢复的旧基础校准伪装成已验证结果，而是报告 `legacy_or_unverified`。双记录写入不应解释为突然断电下的原子事务。诊断接口恢复备份校准到 RAM 时也清除质量认证。

## 主机验证

`tools/calibration_check.py` 保存初始状态、每次请求与完整轮询快照、完成报告、重复性及最终停机状态；检查配置、设备身份、复位/启动时间、已接受校准和质量数据的保留。清理期间的复位或配置变化也记为失败，不覆盖原始失败原因。工具不修改运行配置、不自动保存 NVS，也不自动清故障。输出路径必须是新文件，避免覆盖失败证据。

```powershell
python tools/calibration_check.py --port COM7 --firmware-defaults --cycles 1 --output build/calibration-defaults.json
python tools/calibration_check.py --port COM7 --current 0.25 --max-current 0.25 --voltage 3 --cycles 3 --output build/calibration-repeat.json
python tools/calibration_check.py --port COM7 --interrupt-after 1 --output build/calibration-cancel.json
python tools/calibration_guard_check.py --port COM7 --output build/calibration-guards.json
```

`--firmware-defaults` 发送不带电流/电压覆盖字段的裸 `calibrate`，报告中的 `request` 为 `{}`，用于验证固件本身的默认值。未带该开关时，脚本显式发送自己的默认值 0.16 A / 0.25 A / 3 V，不能据此证明固件默认值生效。`knobctl.py calibrate` 不带额外参数时也发送裸请求；可使用 `--calibration-current`、`--calibration-max-current`、`--calibration-voltage` 显式覆盖。

四个主机工具的校准等待期限均为 130 秒；`knobctl.py` 可用 `--calibration-timeout` 修改，两个校准检查脚本用 `--timeout`。`commission.py --calibration-cycles` 表示完整双向校准次数，沿用综合验收行为，末尾仍有显式 NVS 保存。启停检查脚本现在轮询 active，最长 2 秒、遇故障立即退出，避免固定 0.2 秒等待不足以完成 512 样本准备。

guard 脚本要求进入时已有 verified 的校准。它测试非法参数、active 中拒绝校准、offsets 和 verify 阶段取消、低电压饱和退出及故障锁存，逐项检查旧结果和配置不变。它只在确认本次主动注入的 `calibration_voltage_saturated` 后显式 clear；遇到其他故障或传输失败立即停止，不自动清故障。始终在清理时 disable，不保存 NVS。

## 失败记录与修复

首次候选在完整状态序列化期间发生串口超时及设备重启，旧清理逻辑还漏报了重启；[原始记录](../build/calibration-20261106/calibrate-01.json) 保持原样。Console 任务栈从 8192 扩至 16384 字节，并在主机清理阶段补上配置、校准、质量、身份及 uptime 核对。后续不会因为清理命令成功就掩盖已经发生的重启。

第二次候选出现 `calibration_phase_timeout`，原因是同一份仍新鲜的 ADC 帧产生重复任务通知时错误清空相采集窗口；[原始记录](../build/calibration-20261106/calibrate-02.json) 保留。现在重复通知直接跳过，不贡献新样本也不破坏窗口；新的无效帧或过期帧仍按原规则归零/拒绝。没有删除物理采样窗口保护。

0.08→0.12→0.16 A 的后续完整扫描确实完成了测量，但机械回差与残差不满足条件。默认激励据实改为 0.16 A 起步、允许最高 0.25 A、3 V；质量门限保持不变，没有将失败数据标成成功。

采样检查中的少量 pair_change 在原 v16 对照中也出现。代码审查支持一种既有路径：quiet_output 的立即零输出优先于两相采样配对，跨越该变化的帧被拒绝，不进入 PI。该证据不能把严格失败改记为通过，也不能证明所有被拒帧都只有这一原因；本轮未修改 HAL 的立即落零保护。另发现新增的每次 status 扫描控制任务栈水位会影响调度，因此改为仅在电机未激励时读取 control_stack_free，运行时返回上次缓存值。最终复测中 reused/missed 增量均归零，有效频率恢复至约 5 kHz；末次 pair_change=0 不意味着立即落零的既有例外已被消除，也不构成所有运行条件下永不拒帧的保证。

## 物理验证边界

软件回归和板上遥测可验证数学拒绝条件、状态迁移、配置保留及被测装配的重复性。它们不能独立确认电流绝对增益、真实相电流纹波、机械输出转矩、全工况温升或外部角度精度。本轮不将内部 Id/Iq 跟踪、重建三相电流和为零或正反向运动，解释为这些物理量已完成标定。相电阻、电感辨识及电流 PI 自动整定也不属于本次传感器对齐结果。
