# 2026-11-06：PWM 不低于 15 kHz 的 SVPWM 电压利用率测试

本轮在 COM7 的 ESP32-S3 / DRV8316CT / MT6701 / 22008 空载装配上，按用户要求保持 PWM 载波不低于 15 kHz，寻找既能提高电压圆、又满足现有电流反馈验收条件的配置。**最终选择并烧录 78.3571% 档位，载波 15003.7509 Hz，相对原 65% 电压能力提高约 20.55%。** 该档位先完成七次最短窗口检查，合计请求驱动 87 秒；最终镜像另完成 30 秒检查，拒帧率 **0.77467%**，通过小于 1% 的既定门槛。更高的 78.6572% 档位因拒帧率 1.5301% 失败。上述电压能力属于板上采样与 PWM 锁存路径证据，不是外部仪器测得的电机端电压。

## 利用率定义及采样预算

本文的利用率是线性 dq 电压幅值相对理想 SVPWM 电压圆的比例：

`η = sqrt(Vd² + Vq²) / (Vbus / sqrt(3))`

它不是电源到电机的功率效率，也不等于任意方向下的最高单相 duty。零相钳位调制中，相同 dq 幅值在不同电角度会产生不同的最大相 duty。本轮 20 kHz 基线高输出的最大相 duty 只有 56.35%，但锁存矢量利用率已是 65.0097%；后者略超过 65% 是比较值量化造成的差异。[基线分析](../build/svpwm15-20261106/baseline-utilization.json)

载波使用 80 MHz 定时器；新档位每半周期 2666 ticks，实际频率为 **15003.7509 Hz**，满足 15 kHz 下限。控制每四个载波更新，标称 **3750.9377 Hz**；编码器每六个载波触发，标称 **2500.6252 Hz**。两相电流分别在相邻载波采样，名义间隔 **66.65 µs**，整数时间戳通常显示 66/67 µs。原 20 kHz 档控制为 5 kHz、相采样间隔约 50 µs。新档位减慢了控制节拍并增加相间时间差，不能把空载静态验收当作完整动态响应等价证明。[时序定义](../components/knob_hal/include/board.hpp)

所有候选保留下降沿后 **6 µs** 建立时间、上升沿前 **1 µs** 保护、真实 START/DONE 与 DMA 数据绑定、两相之间的 PWM 一致性检查，以及已有过流、编码器和反馈恢复保护。慢时序的数字 ADC 控制器为 10 MHz；FAST 使用 40 MHz 数字控制器，两者模拟 SAR 均为 **5 MHz**。FAST 改变数字同步开销，没有超频模拟 SAR。[共享采样预算](../components/knob_core/include/sampling_timing.hpp)、[ESP-IDF ADC LL](https://github.com/espressif/esp-idf/blob/v5.5.6/components/hal/esp32s3/include/hal/adc_ll.h)、[ESP32-S3 TRM](https://documentation.espressif.com/esp32-s3_technical_reference_manual_en.pdf)

## 测试方法与门槛

使用固件有界 d 轴注流诊断：先以 0.3 A 请求检查，再以 0.8 A 请求逼近电压饱和；每次由固件限时、限制运动并在结束后关闭输出。电流请求不等于实际达到的电流。`stall_window_check.py` 按以下条件验收，任何一项失败都会保留 `passed:false`，取消后续升档：

- 驱动观测区间有效控制速率大于标称的 98%；新档位门槛为 **3675.919 Hz**。
- 驱动拒帧率严格小于 **1%**，分母为有效控制数与拒绝采样数之和。
- 整轮 ADC transport、pair_change、反馈恢复增量为 0，诊断正常完成且无锁存故障。
- 电流刺激有实际观测证据；额外指定最小 duty 时，须由本轮有效 ADC 快照的锁存比较值证明，不能使用指令值或启动以来的累计峰值。

最初的固定方向高输出测试到达电压圆，但未把最高相 duty 推到上限。例如 73.7434% 候选最小 compare 为 895，而非合同下限 700；这不能证明最短窗口健康。随后为 d 轴诊断增加显式 `electrical_offset`，范围 ±π/6 电角度，选择靠近 `30° + n×60°` 的固定定子矢量。它只改变本次测试参考系，不修改已接受的电角度零点；原运动保护和驱动限时继续生效。[诊断定义](../components/knob_app/include/diagnostics.hpp)、[验收工具](../tools/stall_window_check.py)

## 时序证据及其限制

离线工具将电压估算限定于 `adc_sample_valid/current_valid` 为真、两相载波一致的快照；使用 `after[0] == before[1] == after[1]` 的比较值重建电压，不混入第一槽前的旧命令。另设独立时序统计，保留元数据能够证明 DONE 关联的被拒绝样本，缺少关联证据则计为 unavailable，避免只看有效样本而漏掉迟到转换。[离线报告工具](../tools/voltage_utilization_report.py)、[离线测试](../tests/voltage_utilization_report_tests.py)

77.49 最短窗的 USB 快照全部落在被接受的采样上，记录到 DONE 最大 519 ticks、最小上升沿裕度 **0.0125 µs**；但完整计数器明确记录了 70 次窗口拒绝。78.66 的 253 份 drive 快照中捕获了 **2 份**被拒绝样本，独立关联验证均完整；其 DONE 最大 542 ticks、最小上升沿裕度 **−0.6625 µs**，直接显示越过规定采样窗口。USB 只捕获到 2 份不能替代累计 **686 次**拒绝计数，也不能用 USB 的最大 DONE 当作所有转换的最坏延迟。

最终 78.3571% 镜像的 30 秒检查采集 639 份 drive 快照，其中 634 份 ADC 有效、5 份相窗口拒绝，全部具备独立时序关联证据。被拒绝快照的最小上升沿裕度为 **−0.3375 µs**。尾半段 319 份快照中有 317 份有效，全部达到电压圆；不能把这 317 份有效样本的利用率平均值解释为包含所有失采区间的外部电压时域平均。整轮 872 次拒帧与驱动观测区间的 870 次须各自保持统计范围。

本轮没有差分电压探头、示波器波形或外部相电流标定。板上锁存比较值能证明固件向 PWM 硬件提交并跟踪的调制行为，但电机端电压仍受驱动传播、死区、器件压降和脉宽响应影响。高输出实机证据限于上述 B 相高端、90°/150°固定参考及各次持续时间，未覆盖长期温升、三相分别为高端、全部电角度连续旋转、负载变化或声音验收。
