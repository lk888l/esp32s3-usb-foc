# 2026-11-05：提高占空比与降频实测

目标为将原 `20k65_sampling` 的电压能力从 `0.65 × Vbus / √3` 提高到 85%–90%。用户允许降低 PWM 频率，并授权连接设备空载测试；随后明确反馈 5 kHz 蜂鸣尖锐，允许短测 10 kHz 评估声音。

**最终结果：用户反馈 10 kHz 也仍然尖锐，并要求恢复 20 kHz。设备与源码默认配置均已恢复原 v16 / 20 kHz / 65% / 5 kHz 电流环。提高到 85%–90% 的目标本轮未完成，两种降频方案均未通过声音验收。** 最终为 `idle / fault:none / duty=[0,0,0]`，本轮开始时完整 RAM 配置及校准完全一致，未保存 NVS。[最终状态与镜像核对](../build/duty90-20261105/final-state.json)

## 5 kHz / 90% 候选（未通过整体验收）

`dma-v17-5k90-sampling / 5k90_sampling` 使用 5 kHz PWM、90% duty、1.25 kHz 电流环。最短 LOW 为 20 µs，容纳原 17.5 µs 采样预算；保留真实 START/DONE 校验、DMA 数据绑定、两相指令一致性与保护。编码器采集仍为 2.5 kHz，电机任务通常按 1.25 kHz 消费角度，两相电流采样相差 200 µs。

0.3 A 请求的 3 秒测试通过：驱动有效控制约 1249.75 Hz，采样拒绝、恢复、传输异常和两相指令变化均为 0；后半程 Id 快照均值约 0.271 A。随后 0.8 A 请求过程中捕获到 **89.875% 实际锁存 duty**（由前两槽比较值推导），证明硬件锁存路径确实到达目标区间；该阶段触发 `diagnostic_motion_guard`，停止后续加流，不能作为持续高输出验证通过。

用户同时反馈蜂鸣非常尖锐，因此停机并回滚 v16 / 20 kHz / 65%，恢复本轮开始时的完整 RAM 配置与校准。未写 NVS。5 kHz / 90% 的修改最终仅归档在实验补丁中，不作为源码默认或声音合格方案。

原始记录：[低电流](../build/duty90-20261105/low-current.json)、[高输出失败](../build/duty90-20261105/high-short.json)、[停机](../build/duty90-20261105/stopped-noise.json)、[回滚与参数恢复](../build/duty90-20261105/restored-v16-noise.json)。

降低电流环速率会改变动态响应与过流检测粒度；即使电流阈值保持不变，也不等同于原 5 kHz 环的响应时间。板上遥测不是外部电流或端口电压标定，锁存比较值也不等同于示波器实测波形。

## 10 kHz / 85% 候选（声音未通过，高输出未验证）

用户授权短测 10 kHz 后，制作 `dma-v18-10k85-sampling / 10k85_sampling`：10 kHz PWM、85% duty、2.5 kHz 电流环，电压圆为 `0.85 × Vbus / √3`，两个有效相样本相差约 100 µs。数字 ADC 时钟提高至 40 MHz，SAR 时钟仍为 5 MHz；START 目标为 TEZ 前 1 µs。此分频方式符合 [ESP-IDF ADC LL](https://github.com/espressif/esp-idf/blob/v5.5.6/components/hal/esp32s3/include/hal/adc_ll.h) 的编码与 [ESP32-S3 TRM](https://documentation.espressif.com/esp32-s3_technical_reference_manual_en.pdf) 的 SAR 时钟要求，但资料不保证完整 START 到 DONE ISR 延迟。

停机采集 80 份快照、160 个有效槽观察，START 到 DONE 平均约 **6.864 µs**，DONE 相对 TEZ 最大约 **+6.038 µs**；全部满足 85% 对应 15 µs LOW 窗口的 START ≥ −1.5 µs、DONE < +6.5 µs 条件，拒绝增量为 0。最初 +5.5 µs 设计预算偏紧，据此将归档候选的预算修正为 +6.1 µs、额外余量 31 ticks（0.3875 µs）；物理 6 µs 建立和 1 µs 上升沿保护不变。

2 秒、0.3 A 请求短测完成：有效控制约 **2500.25 Hz**，拒绝、反馈恢复、传输异常和两相指令变化均为 0；后半程 Id 快照均值约 **0.264 A**，最高锁存 duty 约 **34.75%**。此测试只证明所测低输出范围的采样健康，**没有验证 85% 持续高输出，也没有达到请求电流的 90% 判据**。用户反馈声音仍尖锐后停止进一步加流，并恢复原 20 kHz 固件。

候选通过 23/23 桌面测试。原始记录：[停机时序](../build/duty90-20261105/idle-timing-v18.json)、[声音短测](../build/duty90-20261105/sound-low-v18.json)、[最终回滚](../build/duty90-20261105/restored-final-v16.json)。实验代码、Kconfig 和回归归档于 [experimental-profiles.patch](../build/duty90-20261105/experimental-profiles.patch)，固件源文件与默认配置已撤回这些实验修改，防止下次常规构建重新引入尖锐蜂鸣方案。

最终运行镜像 ELF SHA256 为 `7ede88f20e82f607478bc6444c225138e50af6ee2153c016314e39136a003467`，与本轮开始时的 v16 镜像完全相同。母线快照约 11.539 V，电压能力约 4.330 V，仍为 `0.65 × Vbus / √3`。

## 验收工具

`stall_window_check.py` 与 `sampling_health_check.py` 的默认有效控制门槛为设备 `control_nominal_hz` 的 98%，避免把标称频率下降误判为失采；传输、两相指令变化与反馈恢复仍必须为 0。注流工具在某档采样失败后不再继续升档。

`--min-peak-duty` 要求本轮驱动阶段的有效 ADC 快照包含达到门槛的实际锁存比较值；前两槽完成标志、DONE、前后 PWM 数值与两相一致性均需满足。缺字段或无有效快照不能通过，也不使用启动以来累计峰值或仅使用输出指令冒充实测。请求电流、实际 Id、指令峰值和锁存峰值分别报告。
